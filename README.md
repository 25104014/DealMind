# DealMind
AI-Powered Autonomous Negotiation and Secure Payment Platform
DealMind is an AI-powered autonomous negotiation platform that helps merchants and buyers reach mutually beneficial deals while protecting merchant profitability through intelligent safety constraints.

The platform combines AI-driven buyer understanding, autonomous negotiation, and secure Razorpay payment integration in a professional interactive application.

✨ Key Features
🤖 AI Buyer Simulator
🧠 Natural Language Buyer Intent Analysis
🤝 Intelligent Negotiation System
🛡️ Merchant-Safe Pricing Protection
⚡ Fast-Track Deal Acceptance
💳 Razorpay Payment Integration
🔐 Payment Signature Verification
🔊 Automatic Voice Notifications for Payment Status
💬 AI Doubt Clarification Assistant
📊 Merchant Economics Dashboard
🎨 Professional and Interactive Streamlit Interface
🛠️ Technologies Used
Python
Streamlit
OpenRouter API
Razorpay Payment Gateway
HTML, CSS and JavaScript
🚀 How It Works
The merchant configures product pricing and negotiation limits.
The AI analyzes the buyer's requirements and intent.
DealMind performs an intelligent negotiation.
Merchant safety constraints protect the minimum acceptable price.
Once the deal is accepted, a secure Razorpay payment order is created.
The payment is completed and verified.
DealMind provides automatic voice feedback for successful or failed payments.
🔒 Security

Sensitive API keys are stored using environment variables or deployment secrets and are not included in the public source code.
